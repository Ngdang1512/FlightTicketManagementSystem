# Use Case

## Khách hàng
- Đăng ký tài khoản
- Đăng nhập / đăng xuất
- Tìm kiếm chuyến bay
- Xem chi tiết chuyến bay
- Đặt vé
- Nhập thông tin hành khách
- Chọn ghế
- Thanh toán
- Xem vé điện tử
- Xem lịch sử đặt vé
- Hủy vé / yêu cầu hoàn vé
- Xem trạng thái đặt vé

## Quản trị viên
- Đăng nhập quản trị
- Xem báo cáo tổng quan toàn hệ thống
- Quản lý tài khoản khách hàng
- Quản lý tài khoản Manager
- Quản lý máy bay
- Quản lý sân bay
- Quản lý tuyến bay
- Quản lý giá vé / hạng vé
- Xem báo cáo / thống kê doanh thu

## Manager / Nhân viên vận hành
- Đăng nhập cổng điều hành
- Tạo và sửa lịch chuyến bay
- Thiết lập nhiều hạng giá và hạn mức ghế cho từng chuyến
- Cập nhật trạng thái vận hành chuyến bay
- Quản lý đơn đặt vé
- Hủy đơn đang chờ thanh toán và hoàn tồn ghế
- Hoàn tiền đơn đã thanh toán trước giờ khởi hành và vô hiệu hóa vé
- Theo dõi thanh toán và tình hình khai thác
